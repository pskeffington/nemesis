# Nemesis — Mac-first distro delivery roadmap

**Goal:** deliver a recoverable, versioned Arch-based Intel Mac image with observed UEFI and device-level acceptance, then expand through independent T2 and Apple Silicon gates.

Statuses: `NOT STARTED`, `READY`, `IN PROGRESS`, `BLOCKED`, `REVIEW`, `ACCEPTED`, `DEFERRED`. Recorded documentation and implementation do not by themselves prove physical success.

## Active pass: M01-P02 — validate preparation and fixture tests
- **Owner:** build-qa-engineer. **Inputs:** ARC-01..05, installed ArchISO or minimal fixture, current scripts.
- **Tasks:** script syntax; ShellCheck; fixture profile staging; package delta dedup; checksum correctness; CI status.
- **Deliverables:** `scripts/validate.sh` evidence, test scripts, repair commits if needed.
- **Gate:** actual passing tests and staged profile checks recorded; source being present is insufficient.
- **Failure/rollback:** preserve worktree/evidence, fix one defect and rerun; no Mac disk operations.

## Next pass: M02-P01 — first real Intel ISO

## Subsequent queue

- **M04-P01 (intel-mac-compatibility):** external boot and feature matrix on selected non-T2 Intel Mac, macOS return confirmed; *no auto internal disk changes*.

## Risk and decision register
- **R01 — T2 support:** missing mainline input/audio etc; separate kernel + firmware, signature policy.
- **R02 — Broadcom:** driver depends on device ID; `broadcom-wl` is inappropriate for t2linux devices.
- **R03 — old EFI:** Intel Mac 32-bit/mixed EFI exceptions may require separate media.
- **R04 — ARM boot:** Apple Silicon M-series require internal boot-policy components; zero-internal-write external boot is not promised.
- **R05 — rolling Arch:** profile/package drift; capture versions and checksums every build.
- **R06 — root build:** scripts reviewed before sudo, no internal Mac repartition or firmware writes.
- **R07 — unsigned third-party repo:** t2linux Arch guide example includes `SigLevel = Never`; Nemesis release blocked until trusted policy defined.
- **R08 — artifact misreporting:** SHA file must be portable and ISO unambiguously new.
