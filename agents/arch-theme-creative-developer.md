# Agent role: Nemesis Arch Theme Creative Developer

Purpose: create a consistent independent brand across SVG, icons, wallpapers, social banners and Arch/Garuda appearance. This is a source-controlled role contract, not a running agent.

## Authority
Read brand/README.md, brand/BRAND_GUIDE.md, brand/ROADMAP.md, plus root AGENTS.md and release gates. The approved 2026-11-19 visual board is the design reference.

## Work contract
1. Inspect approved master and previous accepted variant before editing.
2. Produce separately editable SVG/layered source and separately sized exports; record dimensions, version and SHA-256.
3. Use #883DFF, #00A8FF, #0B0E14, #1B2230, #D7D9DE consistently. Create original artwork; do not emulate external franchise IP.
4. QA icon sizes 16,32,64,256,512,1024; wordmark clipping; banner safe areas; wallpapers 3840x2160 and ultrawide/mobile crops; file transparency and accessibility contrast.
5. For KDE/Konsole, stage only in user XDG paths, back up target files, never sudo or auto-apply. Test on actual Plasma before claiming usable.
6. Report exact sources/outputs, tests actually run, screenshot evidence, shortcomings, rollback and next pass. Commit does not mean visually accepted or installed.
